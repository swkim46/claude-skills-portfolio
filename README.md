# 조사한 정보를 이해와 판단으로 연결하는 AI 업무 시스템

자료를 조사하고 보고서를 만드는 일부터 학습과 투자 판단까지, AI에 맡기는 업무의 범위를 넓혀 왔습니다. 그 과정에서 조사 결과를 다시 사용할 수 있게 저장하고, 근거와 해석을 구분하며, 결과를 검토해 다음 작업을 개선하는 체계를 만들었습니다.

현재는 뉴스레터를 학습 노트로 만드는 시스템, 노트를 읽고 듣고 질문하며 영어를 공부하는 **Compound**, 조사한 사실을 투자 판단과 실행에 연결하는 시스템을 함께 운영합니다. 업무에서 사용했던 리서치·보고서 작성 스킬도 이 저장소에 담았습니다.

제가 정하는 것은 **어떤 문제를 풀지, 결과가 갖춰야 할 기준은 무엇인지, AI가 어디까지 판단하고 실행할지**입니다. AI는 접근 방법을 제안하고 조사·구현·검토를 수행합니다. 저는 결과를 읽고 실제로 사용하면서 변경할 범위와 우선순위를 정합니다.

## 현재 구성

| 업무 | 해결하려는 문제 | 갖춘 구조 |
|---|---|---|
| 리서치·보고서 | 여러 자료를 모으는 데 시간이 들어 결론을 해석할 여력이 부족했습니다. | 조사 목적에 따라 자료를 찾고, 주장과 원문을 대조한 보고서·비교표·인터뷰 기록을 만듭니다. |
| 학습 노트 | 요약만 읽으면 낯선 용어와 사건의 원인을 다시 질문해야 했습니다. | 사건·원인·개념·예외를 연결해 설명하고, 원문 사실과 추가 조사·추정을 구분합니다. |
| Compound | 노트가 쌓여도 긴 파일을 끝까지 읽고 다시 활용하기 어려웠습니다. | 핵심·상세 읽기와 음성, 문맥을 포함한 질문, 영어 표현 학습과 회화 복습을 연결합니다. |
| 투자 | 조사한 사실을 판단에 쓰고, 실행 결과를 다음 판단에 반영할 기록이 필요했습니다. | 사실과 사용처를 연결하고, 근거 판정·주문 검사·체결 확인·결과 평가를 구분합니다. |

업무마다 결과물과 실행 조건은 다르지만, **자료를 확인하고, 판단의 근거를 남기고, 오류를 다음 작업에 반영한다**는 기준은 함께 사용합니다. [전체 구조와 역할](docs/01_전체_흐름과_역할.md)

## 1. 생성한 노트를 실제 학습으로 연결했습니다

뉴스레터를 짧게 줄이는 것보다, 제가 별도 질문을 준비하지 않아도 사건의 배경과 개념을 이해할 수 있는 노트가 필요했습니다. 직접 작성했던 학습 기록에서 설명 기준을 도출하고, 원인이나 제도의 취지가 빠지면 작성 순서부터 고쳤습니다.

이제 Compound에서 핵심부터 읽거나 듣고, 관심 있는 항목의 상세 설명으로 들어갑니다. 모르는 부분을 선택하면 그 문장이 나온 맥락과 함께 ChatGPT에 질문할 수 있습니다. 뉴스레터의 영어 표현은 원문 예문을 가진 카드로 받아 공부하고, 회화 연습에서 고친 표현도 다시 복습에 사용합니다.

노트를 만드는 과정과 그것을 소비하는 화면을 연결하면서, **자료를 생성하는 것뿐 아니라 사용자가 어디서 멈추고 무엇을 더 알고 싶어 하는지**까지 설계 범위를 넓혔습니다. [학습 내용의 기준](docs/03_학습노트_설계.md) · [Compound의 읽기·질문·복습 설계](docs/06_Compound_학습경험.md)

## 2. 사실의 정확성과 판단에 사용할 수 있는지를 나눴습니다

같은 수치가 원문에 있다는 이유만으로 어떤 결론의 근거가 되는 것은 아닙니다. 적용 기간이나 주체가 다를 수 있고, 원문의 ‘예상’이나 ‘잠정’이라는 조건이 빠질 수도 있습니다.

조사한 사실은 종류별 항목과 출처·기준일을 함께 저장합니다. 검증할 때는 값·기간·주체·한정 조건을 나누어 확인하고, 그 사실이 특정 판단 문장을 뒷받침하는지는 별도로 기록합니다. 문장이나 사용처가 달라지면 이전 확인 결과를 그대로 이어 쓰지 않도록 연결했습니다.

공통 저장소를 만들게 된 계기는 사실을 고쳐도 여러 문서에 이전 값이 남는 문제였습니다. 저는 사실과 데이터를 한곳에서 관리하고, 이미 조사한 내용을 다시 활용하도록 요구했습니다. 현재는 값의 변경 이력과 이를 사용한 판단을 함께 추적합니다. [근거를 저장하고 사용하는 기준](docs/05_검증과_개선.md)

## 3. 반복 검토보다 처음 작성하는 구조를 개선합니다

검토를 여러 번 거치면서도 같은 종류의 누락이 반복됐습니다. 저는 검사 기준을 낮추기보다, 작성할 때 필요한 근거와 설명을 갖추는 구조를 만들도록 요구했습니다.

현재는 원문의 단서를 확인할 항목으로 만들고, 인용이 수치를 뒷받침하는지와 필요한 판정이 빠졌는지를 작성 단계에서 확인합니다. 수집한 자료도 본문·영상 자막·설명·접근 안내를 구분해, 확보한 자료의 범위 안에서 사용하게 했습니다. 별도 검토에서 발견한 문제는 현재 결과물의 교정과 다음 작업 방식의 개선으로 나눠 반영합니다.

투자에서는 판단을 마친 뒤 실제 주문·체결까지 이어지는 과정도 분리했습니다. AI가 만든 제안은 프로그램의 검사를 거치며, 주문 접수와 실제 체결을 다른 상태로 관리합니다. [작성과 검토의 연결](docs/05_검증과_개선.md) · [투자 판단과 평가](docs/04_투자_판단과_평가.md)
