# 지식지도(Knowledge Map) 가이드

> `research-verified` 스킬 부속 가이드. 지식지도가 **없을 때 새로 만들고**, 있을 때 **올바로 갱신**하기 위한 개념·위치·형식 안내. **이 스킬은 여러 폴더에서 쓰이고 폴더마다 지식지도가 다르므로**, 아래를 현재 작업 맥락에 맞춰 적용한다. (스킬 0단계=시작 전 확인 / 6단계=종료 후 갱신과 짝.)

---

## 1. 지식지도란

한 **작업 루트(폴더)** 아래 **무엇이 · 어디에 · 어느 버전으로 있는지**를 한눈에 보여주는 인덱스 문서. 목적:
1. 새 세션/터미널이 **즉시 맥락 파악**(무슨 작업이 어디까지 됐는지).
2. **중복 리서치 방지** — 같은 주제를 이미 했는지 리서치 0단계에서 발견.
3. 과거 산출물에서 **외부 1차 원본을 역추적하는 진입점** — 내부 문서 자체는 출처가 아니므로(스킬 0단계), 지식지도로 과거 작업을 찾아 그 〈출처〉의 외부 원본으로 거슬러 올라간다.
4. **핸드오프 허브** — 다른 터미널/사람에게 넘길 때의 목차.

즉 "**프로젝트/워크스트림 × 위치 × 최신 산출물 × 핵심 결과 × 상태 × 핸드오프**"의 표/목록.

## 2. 어디에 두나 — 스코프 2단계 (★ 폴더마다 다름)

이 스킬은 여러 폴더에서 쓰이므로 **현재 작업 루트를 먼저 판별**하고, 그 수준에 맞는 지식지도를 찾거나 만든다.

- **전역(루트) 지식지도** — 여러 프로젝트를 아우르는 최상위 작업 루트에 1개. *프로젝트 단위* 인덱스.
  현 환경 표준: `work/consulting/_지식지도_KNOWLEDGE_MAP.md` (cf. 메모리 `claude-folder-knowledge-map`).
- **폴더(로컬) 지식지도** — 한 프로젝트/워크스트림 폴더가 커서 내부에 여러 리서치·버전이 쌓이면, 그 폴더 안에 *그 폴더 내부 산출물만* 인덱싱하는 자체 맵. 예: `<프로젝트폴더>\_지식지도_KNOWLEDGE_MAP.md`.

**판별 규칙**
- 작업이 *여러 프로젝트 횡단* → **루트 맵**에 프로젝트 행으로 등재.
- 작업이 *한 프로젝트 내부 심화*(그 폴더 안에서 여러 산출물·버전) → 그 **폴더 맵**.
- 루트 맵이 이미 있으면 거기 등재가 기본. 폴더가 독립적으로 비대하면 폴더 맵을 따로 두고 **루트 맵에서 그 폴더 맵을 가리킴**(이중 인덱스).

## 3. 없을 때 — 새로 만들기

1. **위치 결정**(§2) → 해당 루트에 `_지식지도_KNOWLEDGE_MAP.md` 생성(접두 `_`로 폴더 최상단 정렬).
2. **현 루트 스캔** → 기존 산출물·하위폴더·핸드오프·CHANGELOG를 훑어 **초기 항목을 채움**(빈 템플릿만 두지 말 것 — 지금 보이는 것부터 등재).
3. 아래 템플릿(§4)을 쓰되 **현 폴더 실제 내용에 맞게 섹션을 가감**한다(각 폴더 맵은 서로 다르다 — 공통 자료 섹션은 루트 맵에만, 단일 워크스트림 맵은 산출물 목록 위주 등).

## 4. 형식 — 템플릿

```markdown
# 지식지도 — <작업 루트 / 프로젝트명>
> 목적: <이 루트가 다루는 범위 1줄>  ·  최종 갱신: YYYY-MM-DD
> 새 작업/터미널 시작 시 먼저 이 파일 참조. 작업 종료 시 반드시 갱신.

## 공통 자료 (선택 — 루트 맵에만)
- 여러 작업이 공유하는 가이드·스킬·공용 소스·데이터셋 (위치·용도)

## 프로젝트 / 워크스트림
| 코드 | 폴더(절대경로) | 한 줄 설명 | 최신 산출물(파일·버전) | 핵심 결과 | 상태 | 핸드오프 |
|---|---|---|---|---|---|---|
| A | work/consulting/프로젝트X | … | research_X_v3.xlsx | 핵심 수치/결론 | 진행/완료 | HANDOFF_X.md |

## (단일 워크스트림 폴더 맵이면) 산출물 이력
- research_<주제>_v1 → v2 → v3(현행): 변경 요지 / `_raw_sources/` 위치 / CHANGELOG
```

- **필수 열**: 폴더 **절대경로** · **최신 산출물(버전 포함)** · **상태**. 선택: 핵심 결과·핸드오프·기준일.
- 큰 워크스트림은 루트 맵에 **행 1개 + 그 폴더의 로컬 맵 링크**로.

## 5. 갱신 규칙 (리서치 종료 시 필수 — 스킬 6단계)

- 새 산출물 발행/버전업 시 해당 행의 **최신 산출물·핵심 결과·상태·날짜**를 갱신(없던 작업이면 신규 행 추가).
- 경로는 **절대경로**, 버전은 최신 `_vN` 명시, 문서 상단 **최종 갱신일** 갱신.
- 산출물은 덮어쓰기 금지(`_vN` 신규)지만 **지식지도는 *살아있는 인덱스*라 갱신(append/edit)이 정상**.
