# Wording & tone guide

Consulting deliverables read in a specific register. Body text should be neutral, declarative, and analytical — not conversational, rhetorical, or marketing-toned.

## Section titles: noun phrases only

Section titles describe **what is in the section**, not **whether the conclusion holds**.

| Wrong | Right |
|-------|-------|
| "되는 시장인가? → 그렇다, 단 기관성 자산 중심" | "1) 시장 개괄" |
| "어떻게 돈을 버나?" | "3) 수익 모델" |
| "Top 플레이어는 누구?" | "4) 주요 플레이어" |
| "정말 진출해야 하나?" | "Implication — 진출 전략" |

The conclusion belongs in the body, not the title. Question-form titles signal that the writer hasn't decided yet — fatal for a consulting register.

## Body text: avoid colloquialisms

Spoken-Korean phrasings creep in when drafting fast. Strip them before delivery.

| Colloquial | Consulting register |
|------------|---------------------|
| 가장 큼 | 최대 규모 |
| 어떻게 버나 | 수익 구조 |
| 되는 시장 | 성장 가능 시장 / 확장 단계 시장 |
| 잘 나가는 | 시장 점유율 상위의 |
| 돈 잘 버는 | 수익성 입증된 |
| 그렇다 | 사실로 확인됨 / 데이터로 입증됨 |
| 일단 | 우선 / 단기적으로 |
| 마중물 | 초기 시장 조성 / 수요 촉진 |
| 빡셈 / 빡세다 | 엄격함 |
| 조이다 (규제를) | 규제 강화 / 통제 |
| 서빙 (serving) | (고객) 대상 영업 / 서비스 제공 |
| 굴리다 (자산을) | 운용 |
| 되사고팔다 | 매매 / 2차 거래 |
| 깔다 (영업·인프라를) | 구축 |
| 핏 (fit) | 적합성 |

> **★ 비유·은어·외래 약어 금지 — '직관적이되 비즈니스 프로페셔널'(반복 지적).** 직관적 = *쉬운 말*, 프로페셔널 = *구어·비유·은어가 아님* — 둘 다 충족해야 한다. '마중물(priming)'·'빡셈'·'조이다'·'서빙'·'굴리다'·'핏' 같은 비유·구어·외래 약어를 풀어쓰라는 것은 *위 표처럼 정식 용어로 바꾸라는 뜻*이지, 비유적 문장을 그대로 쓰라는 게 아니다. (쉽게 풀되 어휘는 업계 표준·정식 용어.)

> **★ 가운뎃점(·) 띄어쓰기.** 여러 항목을 가운뎃점으로 *공백 없이* 연속 나열(`A·B·C`)하면 글자가 뭉쳐 읽히기 어렵다 → **공백 둔 ` · ` 또는 쉼표**로 띄운다(`A · B · C` / `A, B, C`; 3개 이상 긴 나열은 쉼표 권장). 표 셀·헤더·본문 모두 적용.

## Hedging language: stay precise

Consulting writing avoids both overclaiming and excessive hedging. Use these:

- ✅ "다수의 출처에서 ~로 추정됨"
- ✅ "1차 출처 기준 ~"
- ✅ "시행일은 시행령에 따라 변동"
- ❌ "아마 ~ 일 것 같다"
- ❌ "~ 일 수도 있고 아닐 수도 있다"
- ❌ "확실하지는 않지만 ~"

When uncertain, **say what is unknown and what depends on it**, not "I don't know".

## Mixed-language consistency

Pick one convention per label type and stick to it.

| Label type | Recommended | Avoid |
|------------|-------------|-------|
| Section markers | `<중간 결론>` (Korean) | `<중간 Conclusion>` (mixed) |
| Implication header | `Implication` (English standalone) | `시사점/Implication` (mixed) |
| Source tags | `<Source N>` (English standalone) | `<출처 N>` mixed with `<Source M>` in same file |
| Unit suffix | `M USD`, `B USD` (English) | `100만 달러` mixed with `M USD` in same column |

**The principle:** within one section/column, pick one form. Don't mix Korean and English forms of the same label in the same context.

## Star markers (★) — used sparingly

A `★` next to a row name in a table signals "this is the key example to walk through verbally". 

- Maximum 1-2 star markers per table.
- If 5 things are starred, nothing is.
- See `color-policy.md` for the parallel principle on color use.

## Headlines vs body — pyramid principle

Every numbered section follows this pattern:

1. **One-line conclusion** (the section's takeaway, in body text)
2. **Supporting evidence** (bullets, tables, data)
3. **`<중간 결론>` block** (1-2 sentences: "so what does this mean")

The reader should be able to read just the headlines (section titles + `<중간 결론>` blocks) and get the entire argument. The bullets are evidence for someone who challenges a claim.

## What "consulting tone" is NOT

- **Not formal-academic.** Avoid "본 보고서에서는…", "전술한 바와 같이…". Direct is better than ceremonious.
- **Not marketing.** No "혁신적인", "독보적인", "차세대" unless quoting a source. Adjectives like these signal the writer is selling, not analyzing.
- **Not journalistic.** No "충격적인", "놀라운", "주목할 만한". State the fact; let the reader judge significance.

## Self-check before delivery

- [ ] Every section title is a noun phrase (no question marks)
- [ ] No colloquial Korean ("가장 큼", "되는 시장", "어떻게 버나", etc.)
- [ ] Mixed-language labels are consistent within each section
- [ ] Star markers (★) total ≤ 2 per table
- [ ] No marketing adjectives ("혁신적", "독보적") unless quoted
- [ ] Each numbered section ends with `<중간 결론>` or `Implication`
