# 렌즈: 증권업 (securities)

증권사(투자매매·중개업) 재무를 표준 제조·유통 틀이 아니라 **증권 손익구조**로 해석하기 위한 관점.
`ratios-securities.yaml` + `account-aliases-securities.yaml`(이 폴더)와 함께 사용. L1 = 표준 재무제표만으로 산출 가능 범위.

## 언제 이 렌즈를 적용하나
식별 결과 대상이 **증권사**일 때(예: 고객사 A(증권사)·증권사 B증권·한국투자증권·삼성증권·NH투자증권·키움증권 등).
신호: ① DART 업종코드가 금융·증권 ② 손익계산서에 **'매출액·매출원가·매출총이익'이 없고 '영업수익·영업비용'** 구조
③ 재무상태표가 유동/비유동 구분 없이 유동성 순서로 표시.
→ 이때 `analyze.py --ratios <이폴더>\ratios-securities.yaml --aliases <이폴더>\account-aliases-securities.yaml` 로 분기.
**은행·보험·카드는 손익구조가 또 달라(이자수익·보험료수익·손해율) 이 렌즈로 분석하지 말 것 — 기존 "미지원 안내 후 중단" 유지.**

## 증권 손익구조 (왜 표준 비율이 안 맞나)
- **영업수익 = 수수료수익(위탁매매·IB·자산관리) + 이자수익 + 자기매매(PI)·운용손익 + 기타** 의 *총額(gross)*.
  → '매출액'이 아니라 gross 개념이라, 영업이익률(÷영업수익)은 제조·유통과 **직접 비교 금지**(증권사 간·자기 시계열로만).
- **'매출원가·매출총이익' 개념 없음** → 원가율 분석 부적합.
- **부채총계가 거대**(고객예수금·RP매도·파생부채·차입) → **부채비율은 1,000%+가 정상이라 무의미**. 표준 부채비율/유동비율/이자보상배율은 **쓰지 않는다**(그래서 증권 프로파일에서 제외).
- **이자비용이 본업 비용**(채권·신용공여 자금조달) → 이자보상배율 무의미.

## 무엇으로 보나 (L1 — 표준 재무제표로 산출)
- **수익성(ROE 중심)**: ROE(당기순이익/자기자본) = 증권사 최우선 지표. ROA, 영업이익률·순이익률(÷영업수익), 판관비율(÷영업수익, 보고 시).
- **성장성**: 영업수익·영업이익·순이익·**자기자본** 증가율(YoY). 시황(거래대금·금리)에 민감 → 비교 모드에선 전사 동반(산업요인) vs 한 곳만 역행(당사요인) 판별이 핵심.
- **안정성(증권형)**: 레버리지비율(총자산/자기자본)·자기자본비율. 자기자본 = 영업용순자본(NCR)·IB 투자여력의 토대.

## 구현 메모 (엔진 무수정 fold)
- 분석 엔진(`analyze.py`)은 원본 `dart-analysis`와 **공유**하므로 엔진을 건드리지 않으려고, `account-aliases-securities`가 **영업수익을 표준명 '매출액'으로 fold**한다. 그래서 `ratios-securities`의 expr는 내부적으로 '매출액'을 쓰지만 값은 영업수익이고, 비율 라벨은 '÷영업수익'으로 정확.
- cosmetic: Excel '주요 금액' 행이 '매출액'으로 라벨링되나 값은 영업수익. 안정성 차트는 표준 차트키(debt_ratio/current_ratio)와 안 맞아 증권에선 생략(레버리지·자기자본비율은 Ratios 시트·요약표엔 정상 표기).

## 한계 / 주의
- **레버리지비율(총자산/자기자본 proxy)은 금융위 규제 '레버리지비율(한도 1,100%)'·NCR(순자본비율)과 정의·조정이 달라 동일시 금지.** 추세·peer 비교용 proxy로만.
- **L2(미구현, 향후)**: ① 영업수익 믹스(수수료/이자/PI **비중**) ② **NCR/영업용순자본비율** 등 규제지표 — 정형 API에 없고 **사업보고서 본문·주석**에 있어 증권 전용 원문 파서(경로 B) 필요.
- **비교 모드 비용구조 시트**: 증권 프로파일은 영업수익을 매출액으로 fold하므로 `compare.py`가 분모(매출액=영업수익)로 비용구조를 계산할 수 있다 — 단 판관비 명세(`parse_notes`/`--notes`)를 수집했을 때만, 미수집이면 자동 skip(비율 비교는 정상).
- 연결(CFS) 기본이되, 증권 단일 법인 분석은 별도(OFS)가 더 명료할 수 있음(자회사 포함 여부 확인).
