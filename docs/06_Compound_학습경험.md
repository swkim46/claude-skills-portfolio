# Compound — 읽고 듣고 질문한 내용을 복습으로 연결합니다

[포트폴리오](../README.md) / [학습 노트의 작성 기준](03_학습노트_설계.md)

Compound는 AI가 만든 학습 노트를 휴대폰에서 읽고 듣고, 궁금한 내용을 질문하며 영어 표현까지 공부하는 개인 학습 앱입니다. 노트를 많이 만드는 것에 그치지 않고 실제 학습으로 이어지게 하려고 기획했습니다.

기존 노트는 항목마다 하위 설명이 길게 이어지는 문서였습니다. 파일 맨 앞에는 작성·검증 기록도 있어 내용을 바로 읽기 어려웠습니다. 저는 관심 있는 소식을 핵심부터 보고 필요한 만큼 깊게 읽을 수 있도록 화면을 구성했습니다.

## 같은 내용을 읽는 상황과 듣는 상황에 맞춥니다

노트의 맨 윗줄은 사건과 의미, 하위 줄은 이유와 정의·예외를 담고 있습니다. 이 구조를 활용해 목록에서는 핵심을, 펼친 항목에서는 상세 설명을 보여줍니다. 노트를 앱에 맞춰 다시 작성하게 하지 않고 변환 과정에서 화면과 음성에 필요한 단위를 만듭니다.

이동 중에는 핵심 또는 전체 내용을 듣고, 화면을 볼 때는 읽는 줄을 따라갑니다. 직접 다른 부분을 읽으려고 화면을 움직이면 자동 따라가기를 멈추고, 다시 현재 재생 위치로 돌아갈 수 있게 했습니다. 읽던 곳과 듣던 곳도 이어 볼 수 있습니다.

음성은 핵심·전체를 각각 한 파일로 만들고 항목과 문장의 시작 위치를 연결했습니다. 휴대폰 화면이 꺼졌을 때 파일 전환으로 재생이 끊기는 제약을 고려한 구현입니다. 본문이 바뀌면 다른 음성으로 식별해 예전 음성이 새 글과 섞이지 않도록 했습니다.

## 질문에 선택한 단어가 나온 맥락을 담습니다

노트에서 ‘소부장 기업’을 선택해 질문했을 때, 질문에는 항목 제목과 선택한 낱말만 들어갔습니다. AI는 그 낱말이 어떤 이야기에서 나왔는지 알 수 없었습니다. 저는 선택한 부분이 나온 노트 내용까지 함께 보내도록 요구했습니다.

현재는 선택한 문장과 그 위의 설명을 노트의 순서와 계층에 맞춰 질문에 넣습니다. 이미 선택한 문장을 중복으로 싣지 않으면서도, 하위 문장만 남아 다른 이야기처럼 읽히지 않도록 상위 설명을 보존합니다. 질문을 보내기 전에 사용자도 전달할 내용을 확인합니다.

이 기능은 ChatGPT에 질문을 넘기는 방식입니다. 앱이 임의로 새 맥락을 만들어 보충하지 않고, 사용자가 읽고 있던 자료에서 질문에 필요한 범위를 구성합니다. [문맥 구성 코드](reference/현재_구조_구현근거.md#compound-context)

## 영어 표현을 원문과 회화 경험에 연결합니다

뉴스레터에서 고른 단어·표현은 실제 사용된 예문과 함께 카드로 받습니다. 문장 속 빈칸을 채우고 뜻을 떠올리는 두 방식으로 공부하며, 복습 기록을 바탕으로 다음 학습 시점을 정합니다. 예문 음성을 듣고, 정답을 확인한 뒤 문장 전체의 한국어 뜻도 볼 수 있습니다.

번역과 음성은 표현 이름만으로 연결하지 않고 해당 예문에 연결합니다. 예문을 고치면 이전 문장의 번역이나 음성을 그대로 붙이지 않도록 했습니다. 아직 공부하지 않은 표현은 전체 수와 함께 제시해, 들어온 자료가 일부만 보이고 나머지는 어디 있는지 알 수 없었던 문제도 개선했습니다.

회화 연습에서는 상황·역할·미션과 사용할 표현을 준비한 뒤 ChatGPT로 넘깁니다. 대화 후 결과를 붙여 넣으면 미션 달성, 교정할 문장, 더 자연스러운 표현, 다음에 집중할 내용을 나눠 보여줍니다. 사용자가 고른 표현은 학습 카드로 저장하고 다음 연습에서도 활용합니다.

교정은 틀린 이유를 먼저 보고 스스로 고쳐 말한 뒤 답을 확인하는 순서입니다. 실제 발언을 근거로 교정하도록 요청하며, 텍스트만으로 발음을 평가하지 않게 했습니다. [회화 결과를 받는 형식](reference/현재_구조_구현근거.md#compound-practice)

## 제가 기획하고 확인하는 범위

학습 목적과 화면 흐름, 질문에 담을 내용, 표현을 공부하는 방식을 정하고 직접 사용하며 수정합니다. Claude Code가 구현하고 Codex가 계획과 코드를 검토합니다. 검토에서 발견한 기술 문제와 사용 의도에 맞지 않는 흐름을 구분해 후속 변경을 정합니다.

노트에서 궁금한 부분을 질문하고, 원문에서 접한 표현과 회화에서 고친 내용을 다시 공부할 수 있는 제품으로 연결했습니다.
