# 운영 기록과 집계 기준

[포트폴리오](../../README.md) / 운영 기록

2026년 10월 20일까지 로컬에 남은 기록을 셌습니다. 아래 숫자는 만들어진 자료와 유지보수 기록의 양입니다. 시간 절감이나 학습 효과, 수익률 개선을 측정한 값은 아닙니다.

| 기록 | 수량 | 센 방법 |
|---|---|---|
| 학습 노트 | 36일치 | 날짜별 하나. 같은 날짜의 수정본·감사본·복습본 제외 |
| 투자 분석 노트 | 52회차분 | 9월 9일~10월 20일의 시장·날짜 조합. 국내 25, 미국 27. 같은 시장·날짜의 수정본 제외 |
| 투자 주간 피드백 | 3편 | 10월 3일·10일·17일의 정기 보고서. 수시 검토와 개별 변경 건수는 제외 |
| 감사 지적 기록 | 123건 | 공통 감사 기록의 `finding` 유형. 기록 시각이 10월 20일까지인 행 |
| 검사 기준 반영 기록 | 74건 | 같은 기록의 `promoted` 유형. 같은 기준에 대한 반복 기록과 소급 기록 포함 |

분석 노트 52회차분은 52번의 매매 또는 완료한 실행을 뜻하지 않습니다. 문서가 남은 시장·날짜를 센 값입니다. 공개하는 투자 판단 사례는 이 집계와 별도로 10월 17일까지의 모의투자 기록으로 한정했습니다.

감사 지적과 기준 반영은 서로 다른 종류의 기록입니다. 한 지적에 여러 유형이 붙을 수 있고, 같은 검사 기준이 여러 번 기록되기도 합니다. 따라서 ‘지적 123건 중 74건을 해결했다’거나 ‘새 검사 문항 74개를 만들었다’고 해석할 수 없습니다. 전체 기록의 원문은 공개하지 않습니다.

## 정기 작업

| 주기 | 작업 | 기록으로 확인한 범위 |
|---|---|---|
| 평일 | 학습 노트 | 예약 작업이 학습 스킬을 호출. 사람이 답변하지 않는 상황을 전제로 수행하도록 지시 |
| 국내 시장 평일 09:30 | 국내 투자 | 실행 지침에 정한 시작 시각 |
| 미국 시장 개장 5분 뒤 | 미국 투자 | 서머타임을 고려해 시장 개장 기준으로 시작 |
| 토요일 아침 | 투자 주간 평가 | 해당 주의 거래·보류와 변경 효과를 평가 |

시작 시각과 산출물 완성·주문 전송 시각은 다릅니다. 예약 실행 지침은 사람이 응답하지 않아도 진행하도록 되어 있습니다. 그 사실로 특정 시각에 제가 자리에 있었는지까지 알 수는 없습니다.

## 공개 자료의 성격

- [실제 기록 발췌](../../examples/실제_기록_발췌.md): 업무 가이드의 원문과 학습 노트의 일부, 투자 판단·평가의 요약. 각각 발췌와 요약을 표시했습니다.
- [가상 입력 재현](../../examples/가상_사례_판단_과정.md): 실제 공개 코드의 주문 검사 결과. 입력과 일부 판정 값은 시연용이며, 주문 전송·체결은 하지 않습니다.
- [가상 리서치 보고서](../../examples/컨설팅_가상_사례.md): 결과물 형식을 설명하기 위해 작성한 예시. 실제 고객 과제를 재현하지 않습니다.
- 스킬·실행 코드: 10월 20일의 구성을 설명하며 공개 설정은 모의계좌 모드입니다. 비공개 내부 서식까지 필요한 작업은 공개본만으로 재현할 수 없습니다.

고객 자료와 계좌 정보·성과 수치는 공개하지 않습니다. 생각할 시간과 학습량이 늘었다는 설명은 제 사용 경험입니다. 구현과 기록으로 확인할 수 있는 것, 효과를 계속 평가하는 것은 업무별 문서에서 구분했습니다.
