# 컨설팅 리서치 시스템 — 요청 유형별 처리 경로와 산출물

컨설팅 업무에서는 조사 질문에 답하는 보고서, 준비된 내용을 정리한 Word·Excel 문서, 인터뷰 기록을 만듭니다. 이 글은 요청 유형별로 어떤 경로를 거쳐 무엇이 나오는지, 어디서 프로그램이 검사하고 어디서 제가 확인하는지 설명합니다. 스킬 9개는 요청에 따라 필요한 것만 사용하며, 모든 요청이 한 순서로 실행되지는 않습니다. 펌·고객사·과제·실명은 공개본에서 일반어로 바꿨습니다.

## 세 경로

### 새 조사 질문

| 단계 | 하는 일 |
|---|---|
| 준비 | 지식지도에서 같은 과제가 이미 있는지 확인하고, 새 과제면 폴더와 파일 이름을 먼저 정한다. 과거 내부 산출물은 출처로 쓰지 않고 외부 원본을 찾는 색인으로만 쓴다. |
| 범위 설정과 탐색 | 포함·제외 범위를 고정하고 검색 각도를 여러 갈래로 나눠 후보 자료를 찾는다. 검색 결과의 요약은 인용 출처가 아니다. |
| 원문 확보 | 후보 자료의 원문을 받아 과제 폴더에 저장한다. PDF는 본문을 추출하고, 스캔본은 이미지로 읽는다. 공시 수치는 표를 결정적으로 파싱하고 여러 해의 값을 교차 대조한다. |
| 주장 대조 | 보고서의 모든 주장을 저장한 원문에서 다시 찾아 확인한다. 서로 반박하는 출처가 있으면 폐기하거나 등급을 낮추고, 출처마다 등급을 붙인다. |
| 합성과 산출 | 사실과 분석을 나누고 규모 산식을 점검해 작업 문서(마크다운)를 만든다. 문서 끝에 출처 목록(원문 인용, 번역, 활용 방식)과 검증 메모를 둔다. |

단계별 검사는 자료 흡수, 원문 확보, 발행의 세 지점에 있고 순서가 강제됩니다. 흡수와 발행 뒤에는 백그라운드 감사가 돌며, 발행 직전에는 활성 감사가 모두 통과했는지 확인하는 명령을 거쳐야 완료를 선언할 수 있습니다. 이 명령은 AI가 실행하는 엔진 명령이며 제 승인과는 별개입니다. 고객용 Word·Excel 문서는 아래 문서화 경로가 만듭니다.

### 준비된 조사 내용의 문서화

검증을 통과한 내용만 받습니다. 검증되지 않은 내용이면 조사 경로의 대조 단계를 먼저 거칩니다.

- **Word 보고서.** 문서 유형(분석 보고서 또는 인사이트 전달용)을 고르고, 출처 라벨과 주소를 한곳에서 관리합니다. 본문의 출처 표시는 클릭할 수 있는 링크가 되고, 표의 출처 열과 문서 끝 출처 절이 함께 만들어집니다. 저장 전에 모든 링크가 열리는지 확인하고, 생성된 문서에서 구어·비유 같은 금지 표현을 찾습니다. 판 번호는 자동으로 올리고 이전 판은 별도 폴더로 옮깁니다. 고객용 문서에서는 출처 등급과 분석 표시를 지웁니다.
- **Excel 정리.** 과제 개요, 피라미드 구조의 요약, 출처 모음의 세 시트로 만듭니다. 요약 시트 맨 위에는 핵심 메시지, 핵심 수치표(수치·의미·출처), 흐름, 결론을 둡니다. 계산값은 수식으로 넣고 재계산 도구로 수식 오류가 없는지 확인하며, 저장 뒤 자체 검사가 글꼴, 출처 링크, 줄바꿈, 남은 평문 주소를 확인합니다. 파일 이름이 판 번호 규칙에 맞지 않거나 표에서 세 행 이상 연속으로 강조하면 검사가 막습니다.

두 스킬 모두 한 번 호출에 산출물 하나를 만들고, 출처를 모르는 내용은 지어내지 않고 '출처 확인 필요'로 남깁니다. 문서는 발행 지점에서 단계 검사를 받고, 제게 보여주는 모든 판은 그 판에서 검사와 감사를 거친 뒤에 제시합니다. 제가 손으로 고친 부분은 다음 판에서 차이를 확인해 보존합니다.

### 녹취 텍스트 정리

화자 표시가 사람의 손으로 끝난 녹취 텍스트와 일시·참석자 정보를 받습니다. 화자 표시를 참석자 명단과 맞추고, 확실하지 않은 표시는 표시해 둡니다. 고유명사와 수치는 웹에서 확인합니다.

산출 전에 반드시 마크다운 구조 초안을 제게 보여주고 확인을 받습니다. 초안에는 요약, 섹션 제목, 시사점 후보, 용어 후보, 음성 인식 오류로 보이는 항목이 들어갑니다. 제가 확인하거나 수정한 뒤에 프로그램이 Word 문서를 만듭니다. 문서는 일시·참석, 요약, 번호 섹션, 시사점 또는 후속 조치 표, 용어 풀이로 구성합니다. 녹취에 없는 내용을 보태지 않고, 사람이 붙인 화자 구분을 임의로 고치지 않으며, 전달 메일 본문은 만들지 않습니다. 발행 지점에서 단계 검사와 감사를 거칩니다.

## 경로를 돕는 도구

- **공시 재무 분석.** 상장사의 재무제표를 공시 시스템에서 수집해 비율과 추세를 계산하고 Excel로 만듭니다. 동명 회사가 여럿이면 근거를 달아 추천한 뒤 제 확인을 받고, 분석 구조 초안도 산출 전에 승인받습니다. 금융업·지주사처럼 구조가 다른 회사는 안내 후 중단합니다. 실행 환경용 스킬은 같은 엔진을 사본 없이 쓰고, 공시 키가 없으면 조사 경로가 확보한 원문에서 수치를 옮겨 넣는 모드로 갑니다.
- **전문가 답변 정리.** 전문가 네트워크의 사전 질문 응답 메일을 읽어 응답자 전원을 한 엑셀 트래커에 누적합니다. 원문과 한국어 번역을 함께 두고, 응답하지 않은 전문가는 넣지 않으며, 답변·경력·가능 시간을 지어내지 않습니다.
- **지식지도.** 과제 폴더의 위치와 이름을 정하고, 폴더의 변화를 지도에 반영합니다. 분류 체계는 제가 쓰던 기준을 유지하고 AI가 임의의 틀을 만들지 않습니다. 새 과제를 시작할 때 쓰며, 지도 갱신은 명시적으로 호출할 때만 합니다.

## 제가 확인하는 자리

| 자리 | 확인 내용 |
|---|---|
| 인터뷰 기록의 구조 초안 | 요약·섹션·시사점·용어의 구조를 확인하거나 수정한 뒤 문서 생성 |
| 공시 분석의 기업 식별과 구조 초안 | 동명 회사 선택, 분석 구조 승인 |
| 문서화의 중간 판 | 검사·감사를 거친 판을 보고 피드백. 내용이 확정된 뒤 정식 판으로 승격 |
| 조사 범위와 출처 | 접근할 수 없는 자료의 본문 제공, 무엇을 대조할지 확인 |

조사 경로에는 산출 전 승인 단계가 따로 없습니다. 발행 전 확인은 단계 검사와 감사의 통과 여부이며, 검토 의견은 원문과 차이를 다시 확인한 뒤 선별해 반영합니다.

## 범위와 한계

이 글은 스킬 파일에 정의된 절차와 프로그램의 동작을 설명합니다. 컨설팅 업무의 실제 결과나 고객 성과는 공개하지 않으며, 무인 수행을 전제로 한 업무도 아닙니다. 출처와 주장의 일치 판단은 AI가 하고, 스캔 이미지로만 있는 자료는 확인 불가로 둡니다. 실제 회의록, 서식 가이드, 과제 자료는 공개본에 없으므로 인터뷰 기록 스킬의 서식 참조 단계는 비공개 자료를 전제로 합니다.
