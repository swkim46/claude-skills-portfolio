# 학습 노트의 설명이 충분한지 판단하는 기준

초기 학습 노트는 뉴스의 사실을 옮기는 데 그쳤습니다. 읽는 사람 입장에서는 "이게 뭐지", "왜"라는 질문이 남았고, 요약만 할 것이라면 노트를 만들 이유가 없다는 피드백이 있었습니다.

이후 어떤 항목을 고르고, 사실 아래에 무엇을 덧붙이며, 완성된 노트를 어떻게 다시 읽을지 기준을 정했습니다. 기준은 대부분 실제 노트에 대한 피드백에서 나왔습니다.

## 기록할 항목을 고르는 기준

사실이면 모두 올리는 방식은 선별이 아니라 수집이 됩니다. 항목마다 세 가지를 확인합니다. 자산 가치나 산업 구조에 영향을 주는지, 실제 이용하는 제도나 이해할 원리를 다루는지, 사회의 변화를 보여 주는지입니다. 선별 순서는 직접 쓴 노트의 주제 분포를 따르되, 이미 벌어진 일만 모으면 앞을 볼 수 없으므로 앞으로의 변화를 설명하는 전망도 포함하도록 했습니다.

## 사실 아래에 덧붙이는 설명

하위 항목에는 추가 사실이 아니라 사건의 원인과 작동 과정을 적습니다. 비교 기준이 무엇인지, 영향이 어떤 경로로 전달되는지, 정책이 실제로 작동했는지, 이해관계자가 무엇을 얻는지, 다른 발행분과 어떻게 연결되는지를 확인합니다. 하위 항목이 사실 나열로만 채워진 노트는 요약과 다르지 않다는 피드백이 이 기준의 출발점이었습니다.

용어를 설명할 때는 세 가지를 함께 적습니다. 무슨 제도인지, 왜 그런 규칙이 생겼는지, 이 뉴스와 무슨 상관인지입니다. 한 노트가 법의 이름과 정의만 적고 해당 기업이 왜 소극적인지 설명하지 않아, 정의는 있는데 이해는 없는 상태라는 지적을 받은 뒤 정한 기준입니다.

## 완성된 노트를 다시 읽는 기준

노트를 쓴 AI는 자료를 다 읽어 이미 이해한 상태이므로, 자기에게만 자명한 전제와 중간 단계를 빠뜨리기 쉽습니다. 완성된 노트는 자료를 읽지 않은 사람의 눈으로 다시 읽습니다. 문장만 읽었을 때 "이게 뭐지"나 "왜"가 남으면 설명을 보완합니다. 자주 나오는 문제는 형용사로 설명을 대신하는 것, 연결어만으로 문장을 잇는 것, 기본적인 인과관계를 생략하는 것, 숫자의 의미를 풀지 않는 것입니다. 이 검토를 건너뛴 회차에서 피드백이 몰려 나왔기 때문에 검사 항목으로도 넣었습니다.

## 기준을 확인하는 방법

- 코드 검사: 금지 표현, 원문과의 대응, 중복, 표시 규칙을 스크립트가 확인합니다.
- 단계별 검사: 하위 항목이 원인 설명으로 채워졌는지, 용어에 세 요소가 붙었는지, 다시 읽기를 실제로 했는지를 묻고 파일에서 확인합니다.
- 출처 검증: 원문에 없는 설명은 표시를 붙여 별도로 검증합니다. [정보 검증](01_정보_검증.md)에 정리했습니다.

## 기준의 한계

선별 기준은 한 사람의 노트에서 도출했으므로 다른 사람에게 그대로 맞지 않을 수 있습니다. 설명의 충분함을 재는 수치는 없으며, 피드백과 검토로 확인합니다.
