# 학습 노트의 설명이 충분한지 판단하는 기준

초기 학습 노트에는 뉴스의 사실이 정리돼 있었지만, 읽고 나면 사건이 왜 일어났고 어떤 의미인지 다시 찾아야 했습니다. 저는 설명이 빠진 부분을 피드백하고, 노트만 읽어도 사건의 배경과 관련 개념을 이해할 수 있도록 작성 기준을 보완했습니다.

기록할 내용의 선별, 사실 아래에 덧붙일 설명, 작성 후 검토를 나눠 기준을 정했습니다. 각 기준은 실제 노트를 읽으며 발견한 문제를 반영한 것입니다.

## 기록할 항목을 고르는 기준

항목마다 세 가지를 확인합니다. 자산 가치나 산업 구조에 영향을 주는 내용인지, 실제로 이용하는 제도와 원리를 다루는지, 사회의 변화를 이해하는 데 필요한 내용인지입니다. 선별 순서는 직접 쓴 노트의 주제 분포를 따르되, 앞으로의 변화를 이해하는 데 필요한 전망도 포함하도록 했습니다.

## 사실 아래에 덧붙이는 설명

하위 항목은 주요 사실의 원인과 작동 과정을 설명하는 데 사용합니다. 사실을 더 나열하는 것만으로 설명을 대신하지 않도록 했습니다. 비교 기준이 무엇인지, 영향이 어떤 경로로 전달되는지, 정책이 실제로 작동했는지, 이해관계자가 무엇을 얻는지, 다른 발행분과 어떻게 연결되는지를 확인합니다. 하위 항목이 사실 나열로만 채워진 노트는 요약과 다르지 않다는 피드백을 작성 기준에 반영했습니다.

용어를 설명할 때는 용어의 의미, 제도나 규칙이 생긴 이유, 해당 뉴스와의 관련성을 함께 설명합니다. 한 노트가 법의 정의는 설명했지만 해당 기업의 행동을 이해하는 데 필요한 이유가 빠져 있다는 피드백을 받은 뒤 정한 기준입니다.

## 완성된 노트를 다시 읽는 기준

작성 과정에서 참고한 자료의 내용이 독자에게도 알려져 있다고 가정하면, 필요한 전제나 중간 설명을 빠뜨릴 수 있습니다. 완성된 노트는 자료를 읽지 않은 사람의 눈으로 다시 읽습니다. 문장만 읽었을 때 "이게 뭐지"나 "왜"가 남으면 설명을 보완합니다. 자주 나오는 문제는 형용사로 설명을 대신하는 것, 연결어만으로 문장을 잇는 것, 기본적인 인과관계를 생략하는 것, 숫자의 의미를 풀지 않는 것입니다. 이 검토를 생략한 노트에서 설명이 부족한 부분이 반복돼 검사 항목으로도 넣었습니다.

## 기준을 확인하는 방법

- 코드 검사: 금지 표현, 원문과의 대응, 중복, 표시 규칙을 스크립트가 확인합니다.
- 단계별 검사: 하위 항목이 원인 설명으로 채워졌는지, 용어에 세 요소가 붙었는지, 다시 읽기를 실제로 했는지를 묻고 파일에서 확인합니다.
- 출처 검증: 원문에 없는 설명은 표시를 붙여 별도로 검증합니다. [정보 검증](01_정보_검증.md)에 정리했습니다.

## 기준의 한계

선별 기준은 한 사람의 노트에서 도출했으므로 다른 사람에게 그대로 맞지 않을 수 있습니다. 설명의 충분성은 노트를 읽고 검토하며 평가합니다. 이를 단일 수치로 측정한 결과는 없습니다.
